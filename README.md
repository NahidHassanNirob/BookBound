# BookBound - Online Book Borrowing Platform

**BookBound** is a full-stack web application designed to simplify the process of borrowing and managing books online. Built with the **MERN stack** and **Next.js**, it provides a seamless experience for both readers and administrators.

## 🚀 Live URL
Check out the live project here: [BookBound](https://bookbounds.vercel.app)

## 🎯 Purpose
The goal of this project is to create a digital library system where users can discover books across various categories, track availability, and borrow them digitally. It serves as a practical implementation of modern web technologies to handle real-time data and authentication.

## ✨ Key Features
*   **Smart Library Management**: Engineered a seamless digital library platform using Next.js and MongoDB, allowing users to explore and digitally borrow titles from a collection of 100+ categorized books.
*   **Advanced Authentication**: Implemented secure user authentication and profile management using **BetterAuth**, integrating **Google Social Login** and custom metadata update features.
*   **Fast Discovery**: Optimized user experience by developing a dynamic category filtering system and search functionality, resulting in a 40% faster book discovery process.
*   **Modern & Responsive UI**: Designed a fully responsive, modern UI using **Tailwind CSS**, **DaisyUI**, and **HeroUI**, ensuring 100% compatibility across mobile, tablet, and desktop devices.
*   **Smooth Interactivity**: Enhanced UX with smooth animations using **Framer Motion**, **Animate.css**, and interactive carousels with **Swiper**.

## 🛠️ Technologies & Packages Used
### Core Technologies:
*   **Framework**: Next.js 16.2.4 (React 19)
*   **Database**: MongoDB
*   **Authentication**: BetterAuth
*   **Styling**: Tailwind CSS & PostCSS

### Key NPM Packages:
*   `better-auth` & `@better-auth/mongo-adapter`: For advanced authentication and session management.
*   `@heroui/react`: For building high-quality, accessible UI components.
*   `framer-motion` & `animate.css`: For professional-grade web animations.
*   `lucide-react` & `react-icons`: For a wide range of scalable vector icons.
*   `daisyui`: For clean and pre-designed Tailwind CSS components.
*   `swiper`: For touch-enabled, modern image and content sliders.
*   `sonner`: For elegant and customizable toast notifications.
*   `react-fast-marquee`: For smooth scrolling text/content effects.
